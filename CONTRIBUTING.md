# Contributing

Contributions are welcome.

## Before You Start

Please read:

- `README.md`
- `agent/AGENTS.md`
- `agent/HOW_TO_USE.md`

## Contribution Principles

Changes should preserve the framework's core goals:

- universal support for existing software projects,
- minimal unnecessary model/context usage,
- professional engineering quality,
- reuse before rewriting,
- targeted testing and QA,
- security review only when relevant,
- resumable progress through persistent checkpoints.

## Good Contributions

Examples include:

- improving agent instructions,
- making workflows more usage-efficient,
- adding better project templates,
- improving QA or verification strategies,
- fixing ambiguous instructions,
- adding stack-agnostic examples,
- improving documentation.

Avoid introducing project-specific assumptions into the shared agent framework.

## Pull Requests

Keep changes focused. Explain:

1. the problem,
2. the proposed change,
3. why it improves the framework,
4. how you verified it.

Do not include secrets, private project code, credentials, or proprietary data.
