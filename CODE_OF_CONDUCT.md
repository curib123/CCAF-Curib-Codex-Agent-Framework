# Code of Conduct

## Our Standard

We want this project to be a professional, constructive, and welcoming place for contributors.

Contributors should:

- communicate respectfully,
- critique ideas and code rather than people,
- provide actionable feedback,
- avoid harassment, discrimination, threats, or personal attacks,
- respect privacy and confidential information,
- keep technical discussions focused and evidence-based.

## Unacceptable Behavior

Unacceptable behavior includes harassment, discriminatory language, deliberate disruption, doxxing, threats, and repeated hostile conduct.

## Enforcement

Repository maintainers may edit, hide, or remove contributions and may restrict participation when conduct materially harms the project or its contributors.

This project values rigorous technical disagreement, but expects it to remain professional and constructive.
