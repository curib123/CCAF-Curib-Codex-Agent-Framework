# Existing Project Folder

Place or copy any existing software project into this folder.

Example workspace:

```text
workspace/
├── agent/
└── YourProject/
    ├── src/
    ├── package.json
    ├── docker-compose.yml
    └── ...
```

You can rename `YourProject` to any real project folder name, for example:

- Vrompt
- PocketPOS
- DocumentSystem
- NextFi
- MySaaS
- ExistingApp

The shared `agent/` system does not depend on the project name, framework, language, or architecture.
